# Untitled Tennis Game
**This will be my second ever game made using the Godot engine!**

 This weeks theme for Terra, the program I am making this for, is **"Outside"**.
I plan to include aspects of this outside theme by making lots of custom assets, I will probably still use some that arent original as well. 
# Main Idea

My goal is to have this be a sort of reimagination of _pong_.\
My idea is to take the main mechanic of _pong_, the paddle and ball interception, and have it be played vertically instead of horizontally.
